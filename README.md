# Coach AI 🏆
An AI-powered sports coaching chatbot built with Python and the Anthropic API.

## What it does
- Teaches kids ages 5-17 the rules of any sport in a fun and engaging way
- Helps coaches create training plans for their athletes
- Adapts its tone based on the type of question asked

## How to run it
1. Clone this repository
2. Install dependencies:
   pip install -r requirements.txt
3. Create a .env file in the project folder with your Anthropic API key:
   ANTHROPIC_API_KEY=your_key_here
4. Run the chatbot:
   python chatbot.py

## Built with
- Python
- Anthropic Claude API
- python-dotenv
